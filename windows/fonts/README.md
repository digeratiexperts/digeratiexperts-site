# Bundled fonts

Space Grotesk and Oxanium, variable-weight TrueType builds from the Google Fonts repository (github.com/google/fonts, ofl/), each under the SIL Open Font License 1.1 (OFL-*.txt beside them). The Windows loader loads them from this folder at run time so the window renders in the DE type stack without installing anything; when the folder is missing it falls back to Segoe UI. Redistribution under the OFL is permitted; the fonts are not sold and their names are unchanged.
